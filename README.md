# NEXORA

A premium architecture / development / interiors concept website.

## Stack

- Next.js
- TypeScript
- React
- Framer Motion
- Lucide React
- Custom CSS design system

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Important

NEXORA is a fictional concept project for portfolio demonstration. Project names, locations and copy are intentionally presented as concept work rather than real clients or completed commissions.

## Image note

The starter uses remote Unsplash imagery for rapid prototyping. For production, replace these with properly licensed/local project imagery and move critical imagery into `public/images`.
